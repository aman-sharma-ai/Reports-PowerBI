# Power BI Dashboards

This repository contains **ten interactive Power BI reports** covering sales, e-commerce, human resources, public health, sport and the restaurant industry. Each report transforms a raw dataset into KPI cards, interactive visuals and slicers designed to answer specific business questions.

![Power BI](https://img.shields.io/badge/Power%20BI-F2C811?style=flat-square&logoColor=black)
![Dashboards](https://img.shields.io/badge/dashboards-10-2ea44f?style=flat-square)

---

## Featured Report: Zomato Analytics Dashboard

![Zomato Analytics Dashboard](Screenshot%202024-05-05%20143412.png)

- **Key performance indicators:** average rating (2.67), total restaurants (7,433) and the proportion of restaurants currently delivering (35.6%)
- **Visuals:** cuisines by rating band, rating distribution, online-delivery availability and a world map of restaurant locations
- **Interactivity:** country, price and rating slicers, with page navigation between the Report and Details views
