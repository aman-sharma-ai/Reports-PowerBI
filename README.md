# 📊 Power BI Dashboards

A collection of **10 interactive Power BI reports** covering sales, e-commerce, HR, public health, sport and restaurant data. Each one turns a raw dataset into KPI cards, interactive visuals and slicers that answer a business question at a glance.

![Power BI](https://img.shields.io/badge/Power%20BI-F2C811?style=flat-square&logoColor=black)
![Dashboards](https://img.shields.io/badge/dashboards-10-2ea44f?style=flat-square)

---

## ⭐ Featured: Zomato Analytics Dashboard

![Zomato Analytics Dashboard](Screenshot%202024-05-05%20143412.png)

- **KPIs:** average rating (2.67), total restaurants (7,433), share delivering now (35.6%)
- **Visuals:** cuisines by rating band, rating distribution, online-delivery split and a world map of restaurant locations
- **Interactivity:** country, price and rating slicers, plus page navigation between the Report and Details views
